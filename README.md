## 📌 Project Overview
**NourishGuard AI** is an intelligent ecosystem designed to solve household food waste, reduce monthly grocery bills, and eliminate local food insecurity by connecting surplus edible food directly to nearby shelters and neighbors in real time.

---

## 📂 Repository Contents
- **[`SOFTWARE_REQUIREMENTS_SPECIFICATION.md`](./SOFTWARE_REQUIREMENTS_SPECIFICATION.md)**: Full IEEE 830-style Software Requirements Specification document containing all 16 required sections, architecture models, and use case diagrams.
- **[`index.html`](./index.html)**: Interactive, modern web documentation portal with live Mermaid diagrams, design system, and printable view.

---

## 🌟 Key Highlights & AI Features
1. **Multi-Modal Receipt & Pantry Vision Scanner (TrOCR + YOLOv8)**: Instant grocery logging and dynamic shelf-life estimation in under 4 seconds.
2. **Generative "Zero-Waste Chef" Recipe Engine (LLM + RAG)**: Dynamic cooking instructions using ingredients nearing expiration.
3. **Hyperlocal Predictive Redistribution Matchmaker**: Machine learning-based routing matching surplus food to verified shelters before spoilage.
